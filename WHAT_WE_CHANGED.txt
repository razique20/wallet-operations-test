WHAT WE UNDERSTOOD & WHAT WE CHANGED (QUICK HUMAN SUMMARY)
================================================================================

1. FIXED: WITHDRAWAL DOUBLE-SPEND (RACE CONDITION)
--------------------------------------------------------------------------------
- What was broken:
  If a user had $100 and sent two $80 withdrawal requests at the same millisecond,
  both checked balance before either deducted it. Both succeeded, causing an
  illegal negative balance (-$60).
- What we changed:
  Added database row locking (`with_for_update()`) and a database check constraint.
- Important code:
  `w = db.scalar(select(Wallet).where(Wallet.user_id == user_id).with_for_update())`
  `CheckConstraint('balance >= 0', name='check_wallet_positive_balance')`

2. FIXED: WITHDRAWAL DUPLICATE RETRIES (IDEMPOTENCY)
--------------------------------------------------------------------------------
- What was broken:
  If a user's network lagged and they clicked "Withdraw" twice with the same
  reference, they got charged twice.
- What we changed:
  Checked if the transaction reference was already completed for that user.
  If yes, returns the existing balance without deducting money again.
- Important code:
  `existing_tx = db.scalar(select(Transaction).where(Transaction.reference == req.reference, ...))`
  `if existing_tx and existing_tx.status == 'completed': return {'idempotent': True}`

3. FIXED: CRYPTO DEPOSIT REPLAY & ZERO-CHECK VULNERABILITIES
--------------------------------------------------------------------------------
- What was broken:
  - Submitting the same hash `0xgood` credited 50 USDT over and over (you saw it twice in your screenshot!).
  - It also accepted fake tokens, wrong recipient addresses, and unconfirmed transfers.
- What we changed:
  - Blocked duplicate hashes across all accounts (rejects re-claims with 409 Conflict).
  - Enforced: token must be 'USDT', recipient '0xmerchant', network 'ethereum',
    and confirmations >= 12.
  - Handled provider outages with a clean 503 instead of server crash.
- Important code:
  `if tx.get('token') != 'USDT': raise HTTPException(400, "Only USDT accepted")`
  `if tx.get('confirmations') < 12: raise HTTPException(400, "12 confirms needed")`
  `existing = db.scalar(select(Transaction).where(Transaction.reference == req.tx_hash, ...))`

4. FIXED: DATA PRIVACY & IDOR LEAKS
--------------------------------------------------------------------------------
- What was broken:
  - Any user could view anyone else's transaction by guessing the URL ID `/transactions/1`.
  - The AI endpoint `/ai/ask` let callers pass any `user_id` to peek at other people's finances.
  - Raw secret reference codes were leaked into external AI prompts.
- What we changed:
  - Locked transaction detail to `transaction.user_id == caller`.
  - Stripped out `req.user_id` so callers only see their own account.
  - Redacted internal reference codes from the AI prompt.
- Important code:
  `if not t or t.user_id != user_id: raise HTTPException(404, 'Transaction not found')`

5. FIXED: PERFORMANCE FOR 10 MILLION RECORDS (PAGINATION)
--------------------------------------------------------------------------------
- What was broken:
  `/transactions` loaded EVERY row into memory (`.all()`). At 10 million rows,
  it would crash the server with Out Of Memory.
- What we changed:
  Added limit/offset pagination and compound database indexes on `(user_id, id)`.
- Important code:
  `query = select(Transaction).where(Transaction.user_id == user_id).limit(limit).offset(offset)`
  `Index('ix_transactions_user_id_id_desc', 'user_id', 'id')`

6. FIXED: FRONTEND EXPERIENCE & LIVE UPDATES
--------------------------------------------------------------------------------
- What was broken:
  Empty table with no refresh, no balance, hardcoded user ID, and no forms.
- What we changed:
  - Added live wallet balance card.
  - Added user switcher (User 1 vs User 2).
  - Added 5-second auto-poll and manual refresh button.
  - Added interactive tabs for Withdraw, Deposit, and AI Assistant.
  - Added transaction detail drawer and status badges (Completed/Pending/Failed).
